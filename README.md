# 信号医生 Signal Doctor

无线信号质量智能诊断网页 —— 《人工智能基础与应用》课程大作业

## 项目简介

把通信工程师「看波形、判病因」的经验过程，转化为普通用户也能使用的自动诊断工具。
用户输入一段 RSSI 信号序列，页面在**浏览器本地**完成特征提取与病因判断，
给出质量评分、病因结论、置信度与处置建议，并绘制波形图与频谱图。

纯前端实现，无后端、无依赖、无需联网推理，数据不出本机。

## 快速开始

### 方式一：直接打开（推荐）
双击 `index.html`，用 Chrome / Edge / Firefox 打开即可使用。

### 方式二：本地起服务
```bash
cd site
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 部署到 GitHub Pages

```bash
git init
git add .
git commit -m "init: signal doctor"
git branch -M main
git remote add origin https://github.com/<你的用户名>/signal-doctor.git
git push -u origin main
```

然后在仓库 Settings → Pages 中，Source 选择 `Deploy from a branch`，
分支选 `main`、目录选 `/ (root)`，保存后等待 1～2 分钟，
访问 `https://<你的用户名>.github.io/signal-doctor/`。

> 注意：`index.html` 必须放在仓库**根目录**，否则 Pages 找不到入口。

## 功能说明

| 模块 | 说明 |
|---|---|
| 信号输入 | 内置样例 / 手动调参合成 / 粘贴实测 RSSI 序列 |
| 可视化 | RSSI 时序波形 + 均值参考线；离散傅里叶变换得到的频谱能量图 |
| 诊断结论 | 质量评分、平均 RSSI、估算丢包率、稳定性 + 病因排序 + 处置建议 |

## 诊断原理

1. **特征提取**：均值（强度）、标准差（稳定性）、一阶差分抖动、突刺率、自相关周期性、前后半段漂移
2. **规则打分**：四类病因分别按特征组合打分，再乘以场景先验修正系数并归一化
3. **结论输出**：健康判定优先 → 病因排序 → 建议映射

四类场景的特征分布（各 60 次采样）：

| 场景 | jitter | spikeRate | bestCorr | mean |
|---|---|---|---|---|
| 正常链路 | 1.4 ~ 2.1 | 0.00 ~ 0.06 | 0.20 ~ 0.41 | -58 |
| 邻频干扰 | 5.0 ~ 9.4 | 0.29 ~ 0.51 | 0.16 ~ 0.46 | -68 |
| 多径衰落 | 2.2 ~ 3.2 | 0.03 ~ 0.13 | **0.90 ~ 1.00** | -71 |
| 设备故障 | 10.2 ~ 15.0 | 0.59 ~ 0.85 | 0.15 ~ 0.37 | -80 |

## 局限说明

信号数据全部由数学模型合成，并非真实设备采集，诊断结论仅具演示与教学意义。
若用于生产环境，需采集实测数据重新标定规则参数。
